# Artifact provenance

Every file in `data/` and how it was produced. Hashes are in `SHA256SUMS`
(current state; stamped via OpenTimestamps as `SHA256SUMS.ots`) and in
`SHA256SUMS.precommit` (the manifest as it stood on 2026-08-07, before BLS
published the 2025 thresholds; its proof `SHA256SUMS.precommit.ots` is a
complete Bitcoin attestation — block 961505, mined 2026-08-07 23:18 UTC).

Implementation repository: PolicyEngine/spm-calculator, branch
`max/bls-2026-threshold-correction` (PR #32), commit
`d2746cfacce072f599ffb1788eb195777c6ca9ca` at the time of this revision.
Abbreviated as "impl" below.
